# Landing Page - Next.js, React, TypeScript, TailwindCSS

## Description

This project is a modern, fully responsive landing page designed to showcase my front-end development skills. Built with **Next.js**, **React**, **TypeScript**, and **TailwindCSS**, it highlights my ability to create elegant and high-performance user interfaces.

## Features

- 🌐 **Responsive Design**: An interface that adapts seamlessly to all devices (mobile, tablet, desktop).
- ⚡ **Optimized Performance**: Built with best practices for a smooth user experience.
- 🎨 **Easy Customization**: Modular architecture for effortless updates and extensions.
- 🚀 **Modern Technologies**: Next.js for server-side rendering and advanced features, TypeScript for robust and maintainable code, and TailwindCSS for fast and consistent styling.

## Installation

1. Clone this repository:

   ```bash
   git clone https://github.com/your_username/landing-page-nextjs.git
   cd landing-page-nextjs
   ```

2. Install dependencies:

   ```bash
   pnpm install
   ```

3. Start the development server:

   ```bash
   pnpm dev
   ```

4. Open your browser at [http://localhost:3000](http://localhost:3000).

## Scripts

- Start the development server.

```bash
pnpm dev
```

- Build the app for production.

```bash
pnpm build
```

- Run the app in production mode.

```bash
pnpm start
```
